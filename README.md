# Software-G

## ¿Quiénes somos?

Somos una empresa de desarrollo de software enfocada en crear automatizaciones con Python para facilitar tareas repetitivas y mejorar los procesos de las organizaciones.

Trabajamos en equipo utilizando Git y GitHub para organizar el código, documentar los proyectos y entregar soluciones de manera ordenada.

## Organización del repositorio

* `README.md`: presentación de la empresa y del equipo.
* `CONTRIBUTING.md`: reglas para trabajar en el repositorio.
* `equipo/`: perfiles de los integrantes.
* `src/`: código fuente de las automatizaciones.
* `docs/`: documentación y bitácoras.
* `.gitignore`: archivos y carpetas que Git no debe guardar.

## Colaboración

Los cambios se trabajan en ramas y se integran a `main` mediante Pull Requests:

1. Actualiza `main` antes de crear una rama para una tarea.
2. Crea una rama por Issue y usa un prefijo como `docs/`, `feat/`, `fix/` o `chore/`.
3. Realiza los cambios y crea commits con el formato `tipo: descripción`, en minúscula y en presente.
4. Sube la rama y abre un Pull Request hacia `main`. Incluye `Closes #número` en la descripción.
5. Solicita la revisión del compañero asignado, atiende las observaciones y fusiona solo después de la aprobación.

Consulta [CONTRIBUTING.md](CONTRIBUTING.md) para ver las reglas completas del equipo.
